About me

I like working across design and code. I sketch the main user flow first, then build a prototype to try it on a real screen.

  • UI design

How I work

Map the main flow

I write down what someone came to do and sketch the shortest clear path to finish it.

Build a small prototype

I turn the sketch into a responsive page and try the flow at phone and desktop sizes.

Test and refine

I walk through the page with a keyboard and revise any labels or steps that are easy to miss.
